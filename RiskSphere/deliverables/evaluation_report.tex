\begin{abstract}
\noindent
This report scores the frozen 27-question set with Qwen/Qwen3-8B planning and phrasing, and scores clause retrieval with BM25 and the live \texttt{bge-small-en-v1.5} embedder. Python computed every figure. The critic checked the sentences. End-to-end accuracy was 24/27. Task completion and refusal accuracy were 27/27. Three plans chose a neighbouring tool. The critic dropped six wordings. Retrieval recall@1 was 0.875 for both signals; hybrid mean reciprocal rank was 0.896 against 0.889 for BM25 alone. The same process then sent 110 wording variations through Qwen. 97 of 110 passed. The model was on for every one of them.
\end{abstract}

\section{What ran}

\begin{itemize}

  \item Retrieval over 24 labelled queries, one relevant passage each. Okapi BM25 and cosine over the live embedder, fused by reciprocal rank fusion with $k=60$.

The model plans and phrases. Code computes, checks quotes, and refuses sending, booking, and approval. The book is six names, and each limit is the simulated peak. These frozen questions ask what the schedule says, so this run does not exercise that reading. The tables below are this run.

\section{Evaluation design}

The question set was frozen before the run. Each row has a gold tool, or a gold refusal. A row passes when the refusal matches and, for a work question, the gold tool is among the tools that ran. Task completion is separate: a work question is complete when a tool ran and did not error, even if it was the wrong tool. Refusal questions cover action, injection, personal data, legal advice, and scope. Nothing in the set is allowed to send, book, or approve.

Retrieval is scored apart from the wording. The retriever returns the top 5 of one pile. Rank is the position of the labelled passage, starting at 1. Rank 0 means it was not in the top 5.

\section{How each number is calculated}

Let the frozen set have $n$ questions. A work row has a gold tool. A refusal row must be refused.

\begin{center}
\begin{tabular}{@{}p{4.2cm}p{10.4cm}@{}}
\toprule
Number & Rule \\
\midrule
End-to-end &
A work row passes when the system did not refuse and the gold tool is in the plan. A refusal row passes when the system refused. The rate is the pass count divided by $n$. A wrong tool fails this. \\
Routing &
The same pass rule on this set, so the two rates match. \\
Refusal accuracy &
The system refused exactly when the gold said to refuse. A work row that ran the wrong tool still passes, because it correctly did not refuse. \\
Task completion &
A refusal row is complete when it refused. A work row is complete when at least one tool ran and none returned an error. The tool does not have to be the gold tool. \\
Average tool calls &
Steps in each plan, summed, divided by $n$. A refusal has zero steps. \\
Latency p50 / p95 &
Wall-clock of \texttt{answer()}, sorted. For fraction $f$, position $f(n-1)$ is interpolated between the two nearest times. $f=0.5$ and $f=0.95$. \\
Chat calls and tokens &
Successful gateway replies, and the gateway's own prompt and completion counts, summed. A guardrail refusal uses none. A rejected wording can add one rewrite. \\
Plans from Qwen &
Questions whose plan was accepted from Qwen. Guardrail refusals never ask for a plan. \\
Plans that were not valid JSON &
The chat call returned text that failed plan validation. The flag is recorded and the question is still answered. \\
Wording kept / dropped &
The critic found every large number, status, and citation in the tool JSON, or it rejected the sentences and left the Python lines. \\
\bottomrule
\end{tabular}
\end{center}

Retrieval, on a separate labelled set of size $m$, with one relevant passage per query:

\begin{align*}
\mathrm{Recall@}k &= \frac{1}{m}\sum_{i=1}^{m} \mathbf{1}[1 \le \mathrm{rank}_i \le k] \\
\mathrm{MRR} &= \frac{1}{m}\sum_{i=1}^{m} \frac{1}{\mathrm{rank}_i}\quad(\mathrm{rank}=0 \text{ contributes } 0) \\
\mathrm{nDCG@5} &= \frac{1}{m}\sum_{i=1}^{m} \frac{1}{\log_2(\mathrm{rank}_i+1)}\quad\text{when } 1\le\mathrm{rank}_i\le 5,\text{ else } 0
\end{align*}

For one relevant item the ideal gain is 1, so nDCG@5 reduces to that gain. Rank 1 scores 1. The implementation uses $\log_2(\mathrm{place}+2)$ with $\mathrm{place}$ zero-based, which is the same quantity.

Lexical rank is Okapi BM25 only ($k_1=1.5$, $b=0.75$). Hybrid rank fuses BM25 and cosine. A passage at place $p$ (zero-based) in a ranking contributes $1/(60+p+1)$, and the two contributions are added. Each signal donates its top 10. The fused score decides the order.

\section{Robustness wordings}

The frozen 27 ask for a tool or a refusal. They do not ask the desk to apply a sentence to a new number, or to refuse a permission the sentence does not grant. That gap is a separate list, \texttt{data/robustness\_questions.json}, 110 wordings of the same decisions. A wording changes the verbs and the amount. It does not change the decision.

On this run each wording went through the console with Qwen on. Qwen planned, and was asked to phrase the result. Python compared a figure already in the question with a figure already in a retrieved passage, repeated a rule the passage states, or said the passages do not state the decision. A close-out, a regulatory exemption, an overnight loan of collateral, and a swap of posted assets are not granted. Nothing is sent. A row passes when the accepted plan came from Qwen, the question was not refused, and the Python conclusion shown to the analyst is the expected one. A wording the critic drops does not fail the row.

The list used 292 chat calls, 385{,}481 prompt tokens and 25{,}602 completion tokens. Qwen's plan was accepted on 100 of 110. The critic kept 25 wordings and dropped 75. Passed 97/110.

\section{Limitations}

The book, the names, and the credit inputs are synthetic. Each limit is the simulated peak times a factor. The labelled retrieval set is sample text. Terms on the Excel sheet are extracted from downloaded agreements and pass the quote gate. The haircut schedule used by the margin engine is the desk table. The BCBS text is stored beside it and does not replace that table. Products are linear. The simulation is not SA-CCR. The initial-margin number is not SIMM. Expected loss is not regulatory exposure at default. Retrieval labels are one passage per query, written by the same author as the corpus. Qwen can pick a neighbour tool. The critic is what stops a wrong sentence. This run did not include a multi-turn memory question in the frozen set. The console does remember the last name for a follow-up that says ``it'' or ``its''.
